# 河南科技大学 选课抢课助手

一个运行在你本机、驱动你自己的 Edge 浏览器来抢课的桌面程序。

## 快速上手（3 步）

```bash
# 1. 确认已装 Python 3.8+ 和 Microsoft Edge（Windows 一般自带）
# 2. 安装依赖
pip install -r requirements.txt
# 3. 运行
python jwc_elect.py
```

> 若 `pip install` 连不上（你的机器 pip 走了失效代理之类），用清华源并显式关闭代理：
> ```bash
> pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple --proxy=""
> ```

**环境要求（就这 4 样）：** Python 3.8+ / Microsoft Edge / `selenium` / `webdriver-manager`。
程序会借助 `webdriver-manager` 自动下载与你 Edge 版本匹配的驱动，无需手动配置。

> ⚠️ **适用对象**：本程序是**针对河南科技大学教务系统（青果 EAMS + 深信服 aTrust 网关）**编写的。
> 其他学校若系统结构、CAS 登录、选课页面不同，需要改 `jwc_elect.py` 顶部的 `CONFIG` 选择器后才能使用。

## 为什么这样做（背景，务必先读）

你们学校的教务系统 `jwgl-haust-edu-cn-s.haust.edu.cn` 挂在**深信服 aTrust 网关**后面。
实测证明：**任何人/程序只要不是"真实浏览器"，都会被 aTrust 拦回 VPN 验证页**（纯 requests、带 Cookie 的 requests 全都 302 到 `vpn.haust.edu.cn`，进不去）。

因此，本程序**不抓包直连**，而是驱动你本机的 Edge 浏览器：
- 真实浏览器能穿透 aTrust；
- 登录（学号密码 + 可能的验证码）由**你手动完成**，程序不碰、也不存你的账号密码；
- 登录后程序只负责"到点按志愿顺序自动抢课"。

## 功能

- 图形界面，可添加多个选课志愿（第1志愿、第2志愿…），支持排序。
- 可指定选课页面 URL 和开抢时间。
- 到点后：按志愿顺序循环 → 定位课程 → 点选课 → 检测成功/满员 → 自动换下一志愿。
- 实时日志，可中途停止。
- 设置自动保存在 `settings.json`。

## 运行环境

- Windows + Edge（已装）
- Python 3.10（已确认）
- 依赖：`selenium`、`webdriver-manager`（已安装）

> 如果你的机器 pip 走了一个失效的代理（像本机 `http://127.0.0.1:4088`），
> pip 装包时会连不上。用清华源并显式关闭代理即可：
> ```
> pip install selenium webdriver-manager -i https://pypi.tuna.tsinghua.edu.cn/simple --proxy=""
> ```

## 使用步骤

1. 连好内网或 VPN（不在学校网络时通常要先开 VPN/接入点）。
2. 运行：`python jwc_elect.py`
3. 界面操作：
   - 填「选课页面 URL」（默认已填教务选课地址）
   - 填「开抢时间」，格式 `12:00:00`
   - 「添加志愿」：依次加入你想抢的课程，越靠前优先级越高
   - 点「① 打开浏览器并登录」→ 会新开一个 Edge 窗口
   - **在弹出的浏览器里自己登录教务系统，并进入选课页面**（这一步很重要，程序接管的是你登录好的会话）
   - 点「② 进入选课页待命」
   - 到点前点「③ 开始抢课」，程序开始自动抢；可从日志看进度，随时可「停止」

## 关键：系统开放后，需要校准选择器（必须做）

现在选课系统未开放，我无法抓取你们真实的选课页 DOM。
程序里所有定位页面的选择器集中在 `jwc_elect.py` 顶部的 `CONFIG` 字典，
**当前值是通用占位，开放后必须按真实页面改成实际选择器才能抢到课。**

### 怎么抓真实选择器

系统开放、你能进选课页后，按 F12 打开开发者工具：

1. **选课行定位（row_locator）**：点左上角箭头图标，在页面上点某一行课程，
   看高亮的元素，找到每行都有的共同结构。把"
   行"的 XPath 填进去（默认 `xpath://tr[contains(@id,'course')]` 只是示例）。

2. **课程号单元格（course_no_cell）**：某一行里，显示课程号的那个单元格，相对行的 XPath。

3. **选课按钮（elect_button）**：那行里"选课"按钮的相对定位，如 `.//a[contains(text(),'选课')]`。

4. **成功 / 满员关键词**：点选课后的弹窗或页面提示，把"成功"和"已满"各自的关键词填进
   `success_keyword` / `full_keyword`。

> 青果(EAMS)系统典型结构：
> - 选课时常弹 `alert`（程序已处理）；
> - 行、课程号通常在某个 `<tr>` 内；
> - 具体类名/ID 需以你们页面为准。

### 如何检查是否连上了

被 aTrust 拦是否成功，看程序日志：若拉到「候选课程行数 > 0」，说明页面解析成功；
若为 0 或报"未找到课程"，就是选择器不对或还没进真实选课页。

## 文件说明

## 重要提醒

- 只用于**你自己正常选课**。请遵守学校选课规则，勿用于占名额、恶意抢热门课后转售或干扰他人。
- 部分系统会检测自动化操作频率，程序已加入了合理间隔；但请勿把 `try_interval` 调得过小。
- 教务系统页面结构可能变更，开放后若选择器失效，按上方方法重新校准即可。
