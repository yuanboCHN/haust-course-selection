# 河南科技大学 选课抢课助手

一个运行在你本机、驱动你自己的 Edge 浏览器来抢课的桌面程序。

## 快速上手


```bash
# 1. 确认已装 Python 3.8+ 和 Microsoft Edge（Windows 一般自带）
# 2. 安装依赖
pip install -r requirements.txt
# 3. 运行
python jwc_elect.py
```

> 若 `pip install` 连不上（你的机器 pip 走了失效代理之类），用清华源并显式关闭代理：
> ```bash
> pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple --proxy=""
> ```

**环境要求：** Python 3.8+ / Microsoft Edge / `selenium` / `webdriver-manager`。
程序会借助 `webdriver-manager` 自动下载与你 Edge 版本匹配的驱动，无需手动配置。


## 功能

- 图形界面，可添加多个选课志愿（第1志愿、第2志愿…），支持排序。
- 可指定选课页面 URL 和开抢时间。
- 到点后：按志愿顺序循环 → 定位课程 → 点选课 → 检测成功/满员 → 自动换下一志愿。
- 实时日志，可中途停止。
- 设置自动保存在 `settings.json`。


## 使用步骤

1. 连好内网或 VPN（不在学校网络时通常要先开 VPN/接入点）。
2. 运行：`python jwc_elect.py`
3. 界面操作：
   - 填「选课页面 URL」（默认已填教务选课地址）
   - 填「开抢时间」，格式 `12:00:00`
   - 「添加志愿」：依次加入你想抢的课程，越靠前优先级越高
   - 点「① 打开浏览器并登录」→ 会新开一个 Edge 窗口
   - **在弹出的浏览器里自己登录教务系统，并进入选课页面**（这一步很重要，程序接管的是你登录好的会话）
   - 点「② 进入选课页待命」
   - 到点前点「③ 开始抢课」，程序开始自动抢；可从日志看进度，随时可「停止」



### 如何检查是否连上了

被 aTrust 拦是否成功，看程序日志：若拉到「候选课程行数 > 0」，说明页面解析成功；
若为 0 或报"未找到课程"，就是选择器不对或还没进真实选课页。

## 文件说明

| 文件 | 说明 |
|------|------|
| `jwc_elect.py` | 主程序（界面 + 抢课引擎） |
| `run_selenium_check.py` | 环境自检（验证 Selenium 能否驱动你的 Edge） |
| `settings.json` | 运行时自动生成，保存你的 URL/时间/志愿 |

## 重要提醒

- 请遵守学校选课规则，勿用于占名额、恶意抢热门课后转售或干扰他人。
- 部分系统会检测自动化操作频率，程序已加入了合理间隔；请勿把 `try_interval` 调得过小。
